# PohuismAndroid

Android-приложение на Kotlin и XML (без Jetpack Compose).

## Возможности
- Список четырёх контактов.
- Отдельный экран переписки для выбранного контакта.
- Сообщения пользователя справа, автоматические ответы слева через 1 секунду.
- GitHub Actions собирает тестовый APK автоматически после изменений в `main`.

## Где получить APK
1. Открой вкладку **Actions** этого репозитория.
2. Выбери запуск **Build Android APK**.
3. Дождись завершения, открой запуск и скачай артефакт **Pohuism-debug-apk**.
4. Распакуй ZIP и установи `app-debug.apk` на Android.

Это debug-сборка для тестирования. Ответы в приложении — демонстрационные, не реальные сообщения публичных людей.

## Технологии
Kotlin, стандартные Android Activity, XML layouts, RecyclerView.
